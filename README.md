# Faith Craft

A free, offline Bible adventure game that builds reading skills. No ads, no chat, no accounts.

- **Play:** https://lizzkz-art.github.io/faith-craft/play/
- **About:** https://lizzkz-art.github.io/faith-craft/

Made for iPad. Open the Play link in Safari, then tap Share > **Add to Home Screen** so it opens full screen and works offline.

Progress is saved only on the device. Nothing is collected or sent anywhere.

Bible text: World English Bible (British Edition), public domain. Fonts: Lexend and OpenDyslexic (SIL Open Font License). 3D engine: three.js (MIT).
